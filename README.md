- Chấp nhận nhập T.Tuấn hoặc T. Tuấn.

Deploy Vercel:
1. Giải nén ZIP.
2. Upload toàn bộ file bên trong lên root repository GitHub.
3. Import repo vào Vercel.
4. Framework Preset: Other.
5. Deploy.
